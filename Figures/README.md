# Figures

## Overview

This folder contains visualizations generated during RNA-seq analysis.

## Available Figures

### PCA Plot

Evaluates sample clustering and overall transcriptomic variation.

### Volcano Plot

Displays significantly upregulated and downregulated genes.

### Top 20 DEG Heatmap

Expression patterns of the top 20 differentially expressed genes.

### Top 50 DEG Heatmap

Expression patterns of the top 50 differentially expressed genes.

### GO Enrichment Bar Plot

Summary of significantly enriched Gene Ontology biological processes.

### GO Enrichment Dot Plot

Visualization of enriched GO terms based on significance and gene ratio.

### KEGG Bar Plot

Overview of significantly enriched KEGG pathways.

### KEGG Dot Plot

Pathway enrichment visualization based on significance and gene ratio.

### KEGG Ridge Plot

Distribution of enriched pathways across gene sets.

### Cardiac Marker Expression Plot

Expression trends of key cardiac differentiation markers including:

* GATA4
* NKX2-5
* TNNT2
* MYH6
* MYH7
* TBX5
* SOX2
* NANOG
* POU5F1

### Sample Correlation Heatmap

Pairwise correlation among all RNA-seq samples.

## Purpose

These figures provide visual evidence of transcriptional changes occurring during cardiomyocyte differentiation and facilitate biological interpretation of the RNA-seq dataset.
